Privacy Policy

Effective 2026-05-02. JSON OS runs entirely in your browser. This policy explains the very small amount of data the service touches and why.

Summary

  • JSON documents you load are processed and stored on your device, in your browser's IndexedDB. They are not uploaded to JSON OS or any third-party server.
  • Visiting the site involves the same standard server logs your browser leaves anywhere on the web (IP address, timestamp, request path).
  • We use no cookies and no advertising trackers. We use cookieless, privacy-friendly analytics for page-view counts and Core Web Vitals only.
  • We do not sell, rent, or share data because we don't collect it.

What stays on your device

The following is kept locally in your browser and never transmitted:

  • The text of every JSON document you load, paste, type, or open
  • The JSON Schemas you paste into the Schema panel
  • Workspace state (open tabs, slot layout, expand state, sort/filter, theme preference)
  • Per-origin authentication tokens you type into the (optional) API panel, when present

This data lives in IndexedDB and localStorage on your device. You can clear it at any time using your browser's site-data controls or by opening the developer tools and clearing storage for this origin.

Server logs

The site is hosted on Vercel. Like any website, the host receives a request log containing your IP address, the URL you fetched, the time of the request, and your user-agent. These logs are kept by the host on a rolling basis for security and operational diagnostics. We do not enrich them with personal information.

Analytics

We use Vercel Analytics and Vercel Speed Insights to count page views and measure page-load performance (Core Web Vitals such as LCP, INP, CLS). These tools do not use cookies, do not assign you a tracking identifier, and do not collect personal data or follow you across other sites. Vercel processes the events on our behalf as our hosting provider; see Vercel's privacy policy.

Third-party services we don't use

JSON OS does not load Google Analytics, Facebook Pixel, advertising networks, session-replay scripts, or any cross-site tracker. Outbound traffic is limited to the application bundle, asset downloads, and the cookieless analytics events described above.

Cookies

JSON OS does not set cookies. Theme and UI preferences are stored in localStorage, which is local to your browser and is not transmitted to any server.

Sharing & export

If you choose to download a JSON file, copy to clipboard, or export to CSV, the data only moves to wherever you direct it. JSON OS does not copy that data anywhere.

Children

JSON OS is a developer tool intended for general audiences. It does not knowingly collect data from anyone, including children under 13.

Changes

If this policy ever changes — for example, if we add an optional feature that talks to a server — we will update this page and bump the date at the top. Your continued use after a change means you accept the updated policy.
